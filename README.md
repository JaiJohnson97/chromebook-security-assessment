# 🛡️ ChromeOS Security Assessment

## 📌 Project Overview

This project documents a security assessment of a Chromebook running ChromeOS. The purpose of this assessment was to evaluate the device's security posture by reviewing system settings, browser security, installed applications, storage usage, and overall configuration.

The assessment was performed as part of my cybersecurity portfolio to demonstrate practical experience with system analysis, security documentation, and risk assessment.

---

## 🎯 Objectives

- Evaluate the overall security posture of a ChromeOS device.
- Review browser security settings.
- Inspect installed applications.
- Analyze storage usage.
- Identify potential security risks.
- Recommend improvements to strengthen device security.
