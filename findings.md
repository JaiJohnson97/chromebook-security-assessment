# Security Findings

## Finding 1: Public Wi-Fi Connection
**Risk Level:** Medium

The Chromebook was connected to a public wireless network during the assessment. Public Wi-Fi networks can expose users to eavesdropping, rogue access points, and man-in-the-middle attacks if additional protections are not used.

---

## Finding 2: Limited Available Storage
**Risk Level:** Low

The device has approximately 1.4 GB of available storage remaining. Limited storage can prevent security updates, Linux installation, and other development tools from functioning properly.

---

## Finding 3: Chrome Safety Check
**Risk Level:** Informational

Chrome Safety Check identified security recommendations that should be reviewed, including browser updates, passwords, and permissions.

---

## Finding 4: Installed Applications

Several applications are installed on the Chromebook. Installed software should be reviewed regularly to remove unused applications and reduce the device's attack surface.
