# Security Recommendations

## Recommendation 1: Avoid Public Wi-Fi for Sensitive Activities

Whenever possible, avoid accessing banking, work, or other sensitive accounts while connected to public Wi-Fi. If public Wi-Fi must be used, connect through a trusted VPN.

---

## Recommendation 2: Free Additional Storage

Increase available storage by removing unused applications, deleting unnecessary downloads, and clearing browser cache. Additional free space allows for operating system updates and developer tools such as the Linux environment.

---

## Recommendation 3: Review Chrome Safety Check

Run Chrome Safety Check regularly to identify browser updates, compromised passwords, unsafe extensions, and permission issues.

---

## Recommendation 4: Audit Installed Applications

Review installed applications periodically and uninstall software that is no longer needed. Keeping only necessary applications reduces the overall attack surface.

---

## Recommendation 5: Keep ChromeOS Updated

Enable automatic updates and verify the device is running the latest version of ChromeOS to receive current security patches and bug fixes.

---

## Recommendation 6: Practice Good Account Security

Use strong, unique passwords for every account and enable multi-factor authentication (MFA) whenever available to better protect against unauthorized access.

---

# Conclusion

Overall, the Chromebook demonstrated a functional security posture. The most significant opportunities for improvement include increasing available storage, regularly reviewing browser security settings, and limiting the risks associated with public Wi-Fi usage. Implementing these recommendations will strengthen the device's overall security and improve its readiness for everyday use.
